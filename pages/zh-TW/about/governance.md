社群運作到一定規模之後，需要把決策的方式寫下來，才不必每次重新爭論基本原則。本章程規範 anoni.net 社群的成員角色、決策方式、爭議處理與行為準則，屬於持續修訂的活文件，重大調整都先在 Matrix 公開討論，再提交修訂。

第一次參與的成員可以先略讀「成員角色」、「行為準則」兩節，了解社群對成員的基本期待。資深成員、提案者與需要處理爭議的核心成員，建議完整讀過一遍。

## 適用範圍

本章程適用於以下範疇的協作與互動：

- anoni.net 文件站（zh-TW、zh-CN、en）
- 自架的 Matrix 家伺服器 `im.anoni.net`、CryptPad、Etherpad、Send、SearXNG、Formbricks
- 以 anoni.net 名義舉辦的工作坊、小聚與研討會場次
- 與 EFF、Tor Project、OONI 等國際組織合作時的對外代表
- 社群相關 GitHub repo 的 PR、Issue 與 Discussion

成員以個人身分在外部平台的言行不在本章程的範圍內，在 anoni.net 場域內的言行則需符合本章程。

## 成員角色

社群的角色制度維持低度形式化，以免層級讓新人感到疏離。各角色實際的權限差別主要在帳號層面（誰能合併 PR、誰能審核 Matrix 帳號申請），發言的權重沒有差別。

### 核心成員

核心成員長期投入維運，累積了足夠的技術能力與社群信任，負責以下事項：

- 自架服務的維運與帳號審核
- GitHub repo 的合併權限
- 對外代表 anoni.net 與國際組織交涉
- 章程修訂提案的最終把關
- 處理違反行為準則的爭議

新的核心成員需經現有核心成員以共識決同意才能加入，目前沒有公開的申請流程。

### 貢獻者

貢獻者是有具體產出的成員，產出包括文章、翻譯、程式、活動籌備、設計與研究等，並在 Matrix Public Space 的相關 room 積極參與。

加入方式：在[參與](/join/)頁認領主題、提交 PR，或參與活動籌備，沒有正式門檻。

### 觀察員

觀察員訂閱了電子報、加入了 Public Space，但暫時沒有具體產出。社群以非同步的方式運作，不要求每個人都保持活躍，觀察員同樣受到歡迎。

### 訪客

訪客沒有加入 Matrix，透過閱讀文件與部落格、來信討論接觸社群。寄到 <whisper@anoni.net> 的信件由核心成員輪值處理。

## 決策方式

### 共識決

社群以共識決為基本的決策方式。共識指相關成員都沒有提出反對，不要求全員同意。流程如下：

1. 提案者在 Matrix 對應的 room 提出提案，附上脈絡與選項
2. 至少保留 3 天，讓有意見的成員回應
3. 沒有反對意見即視為通過
4. 有反對意見時進入討論，直到討論出雙方都能接受的版本

大多數的內容、流程與設計決策都適用共識決。

### 投票（例外狀況）

只有在共識決明顯受阻，或時間緊迫需要盡快得出結論時，才改用投票。投票的條件如下：

- 由至少兩位核心成員發起
- 投票資格：所有貢獻者（最近 6 個月內有具體產出的成員）
- 投票方式：Matrix Poll 公開投票，或 CryptPad 表單半匿名投票
- 通過門檻：簡單多數（過半）
- 重大議題（章程修訂、核心成員加入或退出）需 2/3 多數

社群目前幾乎沒有進行過投票，多數情況以共識決就能解決。

### 提案流程

| 影響範圍 | 提案管道 | 決策方式 |
|---|---|---|
| 單篇文章內容、翻譯選詞 | GitHub PR 或 Matrix room | review 時取得共識 |
| 結構性變動（調整導覽、搬移檔案、更改命名） | 先在 Matrix room 討論，再提交 PR | 共識決，3 天緩衝 |
| 自架服務的新增、移除與政策變更 | Matrix 核心 room 與公開 room 同時進行 | 核心成員共識決 |
| 章程、行為準則修訂 | GitHub Issue 與 Matrix 同時進行 | 共識決，至少 7 天緩衝 |
| 對外公開立場（聲明、抗議、支持書） | Matrix 公開 room | 核心成員與多數貢獻者同意 |

## 爭議處理

爭議分成對事與對人兩類。對事的爭議關於如何做某件事，對人的爭議涉及互動衝突或違反行為準則。

### 對事的爭議

對事的爭議依一般的提案流程處理，在 Matrix 提出歧見、列出雙方論點並尋求共識，無法取得共識時進行投票。技術性的爭議可以保留分歧、各自實驗，一段時間後再依結果評估。

### 對人的爭議

成員之間的互動衝突依嚴重程度分流處理：

1. **輕微誤解**：相關成員私下溝通即可
2. **明確違反行為準則**：受影響者可向核心成員回報，由核心成員協助處理（私下對話、公開警告、暫時隔離）
3. **嚴重事件**（騷擾、跟蹤、人身威脅）：核心成員立即移除違規成員的存取權限，事後在公開 room 簡述處置（不揭露受害者身分），並視需要協助受害者報警或聯繫援助資源

涉及核心成員自身的爭議，由其他核心成員處理，必要時邀請外部仲裁。

## 行為準則

### 互動原則

- **互相尊重**：不同背景、技術熟悉度與政治立場的成員一視同仁
- **對事不對人**：批評想法，不批評身分
- **預設善意**：先假設對方的提議出自善意，再討論細節
- **資訊透明**：相關決策盡量在公開 room 進行，私下協調的結果事後同步到公開 room
- **新人友善**：對基本問題保持耐心，把複雜的脈絡拆解清楚

### 合法前提

所有協作與討論以合法用途為前提，社群不協助也不指導以下行為：

- 洗錢、規避稅務、規避經濟制裁
- 騷擾、跟蹤、人身威脅、未授權入侵
- 散布兒少性剝削內容、人口販運、毒品交易
- 在他國對該國公民進行情報蒐集或干預內政

各種人都可能使用匿名與隱私保護工具，社群推廣時以新聞媒體、公民團體、研究者與需要保護自己的個人為對象。發現協作對象有上述違法意圖時，社群會立即終止協作。

### 機敏資訊處理

- 涉及個人資料、未公開研究、敏感受害者身分的內容，依[上傳機敏資訊流程](/join/upload-sensitive/)處理
- 不在公開 room 直接張貼受害者個資或未公開的爆料原文
- 引用敏感報導時保留原作者與來源，不擅自摘要敏感細節

### 對外言行

代表 anoni.net 對外發言（媒體訪問、活動致詞、社群帳號）時，需遵守以下原則：

- 避免發表未經社群討論的政治立場
- 引述社群成員的私下意見前，需取得當事人同意
- 與國際組織（EFF、Tor Project、OONI）交涉前，先在 Matrix 同步

成員以個人身分對外發言時，註明「個人立場，不代表社群」。

## 違反處置

違反行為準則的處置由核心成員依個案決定，可能的處置由輕至重如下：

1. **私下提醒**：核心成員私訊提醒，不留公開紀錄
2. **公開警告**：在相關的 Matrix room 公開記錄違規行為
3. **暫時隔離**：暫停 Matrix 帳號、CryptPad 存取與 GitHub 權限，期間數天到數週
4. **永久移除**：撤銷所有自架服務的帳號、合作關係，以及參與社群相關活動的資格

核心成員決定處置時，會考量違規的嚴重程度、是否累犯與當事人的態度。重大事件的處置決定會在公開 room 簡述，不揭露受害者身分。

## 章程修訂

本章程是活文件，任何人都可以提案修訂，流程如下：

1. 在 GitHub 開 Issue，說明要修改的內容與理由
2. 同時在 Matrix 公開 room 通知
3. 保留至少 7 天的討論期
4. 取得共識後，由核心成員合併進 `main`，並在部落格簡短說明異動

遇到緊急狀況（例如出現新型騷擾手法，需要立即更新處置原則），核心成員可以先行臨時更新，並在 7 天內回到正規程序檢討。
