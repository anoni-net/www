## 不需要帳號的參與方式

很多事不需要帳號就能開始：訂閱[電子報](/contact/)跟上社群動態、用[服務](/services/)裡的 SearXNG 搜尋與 Send 傳檔、讀文件站[指南](docs:guides/)裡的隱私文章。想進一步參與討論，再來信申請 Matrix 帳號。

## 加入討論

到 Matrix 說明自己對哪一個主題有興趣，在對應主題的房間留言就可以。方便後續分組與協作，也讓其他夥伴知道誰在做什麼。

建議先加入社群的 Public Space，一次取得所有相關房間的入口。

[加入 Public Space](https://matrix.to/#/#community:im.anoni.net){ .btn .solid }

!!! note "還沒有 Matrix 帳號？"

    `im.anoni.net` 採申請制，先來信 <whisper@anoni.net> 取得帳號。已經有 `matrix.org` 帳號的話，直接用原本的帳號加入也可以。等待回覆的期間，可以先訂閱電子報、讀下面三大主題的介紹，想好自己想投入哪個方向。

## 平時如何參與

- **日常討論**：以 Matrix 房間為主，各主題可依需要建立或使用對應的房間。
- **共筆協作**：用 CryptPad 撰寫共筆、活動紀錄或敏感內容。
- **線上視訊**：定期或主題討論時用 Jitsi 開會，連結會在 Matrix 公布。

這幾個工具的帳號申請與入口見[服務](/services/)。
