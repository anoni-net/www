![匿名网络工作坊招募工作人员与培训助手](docs:assets/images/event-workshop-2025.png){ .shot }

新闻记者、公民团体与人权倡导者在工作中面对通信遭拦截、身份遭追踪的风险，受访者的安全也可能因此受到威胁。匿名网络工作坊为他们安排了两天的实操与讨论，用开源的匿名网络工具把通信的掌控权取回自己手上，减少对单一平台的依赖。

- 日期：2025/08/09（星期六）、2025/08/10（星期日）
- 地点：国立台湾科技大学 研扬教学大楼 TR-510 教室
- 形式：工作坊、圆桌讨论

!!! info "活动记录"

    工作坊已经结束，页面保留当时公布的议程。各场次的协作笔记可以从议程表的「协作笔记」链接阅读，活动之后的整理见[2025/08 项目进度更新](/updates/2025/09/updates-202508/)。

匿名网络社区 anoni.net 负责技术支持与实操指导，介绍 [Tor](docs:tools/what-is-tor/)、[Tails](docs:tools/what-is-tails/)、[OONI](docs:tools/what-is-ooni/) 等开源匿名网络工具，带参与者准备第二台安全设备、以匿名方式连接，并实际测量网络审查。

## 工作坊的学习内容

### 数字安全与匿名技术

- 用 Tor 网络匿名浏览
- 以 Tails 与 USB 闪存盘建立**第二工作环境**，不在使用的电脑上留下记录
- 基础的威胁模型评估，包含认识对手、评估风险与对应的行动
- 在网络受到审查的国家或环境，用网桥（bridge）与 [Snowflake](docs:tools/tor-snowflake/) 连上 Tor

### 实操与工具

- 用 Tails 制作**便携式匿名操作系统**，在公用或不受信任的设备上安全工作
- [OONI Probe](https://ooni.org/install/) 测量网络审查与服务封锁的方式，以及把结果回报到全球公开的数据库
- 用 [Tor Browser](https://www.torproject.org/zh-CN/download/) 与 [OnionShare](docs:tools/onionshare/) 安全地分享文件与协作

### 社区支持与持续学习

- 台湾本地的匿名网络社区（见[关于我们](/about/)）
- 参与国际开源项目（例如 Tor、Tails、OONI）的贡献方式
- 活动后的技术咨询与进阶学习资源

### 适用情境

- 采访敏感议题、联系**举报人**与**[吹哨人](https://zh.wikipedia.org/zh-cn/%E5%90%B9%E5%93%A8%E4%BA%BA)**、跨境协作核实资料
- NGO 跨国合作，或在网络受到限制的国家与地区倡导时，建立匿名的通信与行动渠道
- 组织内部数字安全培训与 SOP 制定的参考基础

## 圆桌讨论的主题

### 本地参与与基础建设

- **开源与匿名网络**：Tor、Tails、OONI 背后的开源理念，以及保护隐私、抵抗审查为何需要自由软件。
- **本地参与**：台湾的用户如何成为 Tor 与 OONI 的本地贡献者，让匿名网络工具更贴近本地的语言与文化。
- **社区节点的建立与运维**：协助架设 Tor relay、OONI 测试点等基础节点，参与网络自由的基础建设，同时认识其中的风险与贡献方式。

### 去中心化的推广与协作

- **台湾本地的开源匿名工具包**：把这些工具整合成 NGO、新闻媒体与独立记者容易上手的匿名工具包。
- **去中心化推广的策略与挑战**：去中心、开源协作的推广计划如何在台湾落地，以及教育、技术与社区三方面的人力如何分配。
- **与印太地区匿名网络社区的连接**：区域合作的潜力与现状，以及与印太地区其他倡导者交流、协作的方式。

## 各场次内容

### 场地

活动分成工作坊与圆桌讨论两种形式，在两天内进行，场地约可容纳 30 到 45 人。

- 日期：2025/08/09（星期六）、2025/08/10（星期日）
- 地点：国立台湾科技大学 研扬教学大楼 TR-510 教室
    - 教学大楼位于基隆路三段 155 巷、台大癌医中心那一侧，从台科大正门进入要走一段距离
    - 位置见[学校地图](https://www.ntust.edu.tw/p/412-1000-102.php?Lang=zh-tw)上标记 `15` 的建筑

### OONI 网络审核干预数据分析

- 时间：`2025/08/09 12:30 - 13:30 UTC+8`{style="color: #2e7d32; font-weight: bold;"}
- 内容：
    - OONI 计划简介
    - OONI Probe 的运作方式
        - 移动设备版的安装与使用，以及台湾观测名单未更新的问题
    - 用 OONI Explorer 界面解读观测数据
        - 时间区间的数据、国家与类别的比较、观测结果的判定
    - 用 OONI Run v2 建立观测网站名单
        - 建立自己的观测名单，并在 OONI Explorer 查阅自己的观测结果
    - 其他与 OONI 类似的观测计划
        - Cloudflare Radar、IODA、Sinar Project

### Tor/Tails 匿名网络工作坊

- 时间：`2025/08/09 13:30 - 15:30 UTC+8`{style="color: #2e7d32; font-weight: bold;"}
- 内容：
    - 第二台设备的概念与使用情境
        - 把工作与个人活动分开，保护在线身份与数据
    - Tails 匿名操作系统
        - Tails 与 Tor 洋葱网络的整合，以及如何用来匿名浏览与通信
    - Tor 的运作原理
        - 连上 .onion 网站的方式
    - 实际安装 Tails
        - 在 USB 闪存盘上安装并设置 Tails，用于线上与离线的安全操作

两场工作坊都需要用到笔记本电脑，参与者自备设备，现场另外架设了临时网络供教学使用。
