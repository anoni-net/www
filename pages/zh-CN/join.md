## 第一次来

很多事不需要账号就能开始：订阅[电子报](/contact/)跟上社区动态、用[服务](/services/)里的 SearXNG 搜索与 Send 传文件、读文档站[指南](docs:guides/)里的隐私文章。想进一步参与讨论，再来信申请 Matrix 账号。

## 加入讨论

到 Matrix 说明自己对哪一个主题有兴趣，在对应主题的房间留言就可以。这样方便后续分组与协作，也让其他伙伴知道谁在做什么。

建议先加入社区的 Public Space，一次取得所有相关房间的入口。

[加入 Public Space](https://matrix.to/#/#community:im.anoni.net){ .btn .solid }

!!! note "还没有 Matrix 账号？"

    `im.anoni.net` 采申请制，先来信 <whisper@anoni.net> 取得账号。已经有 `matrix.org` 账号的话，直接用原本的账号加入也可以。等待回复的期间，可以先订阅电子报、读下面三大主题的介绍，想好自己想投入哪个方向。

## 平时如何参与

- **日常讨论**：以 Matrix 房间为主，各主题可按需要创建或使用对应的房间。
- **共笔协作**：用 CryptPad 撰写共笔、活动记录或敏感内容。
- **在线视频**：定期或主题讨论时用 Jitsi 开会，链接会在 Matrix 公布。

这几个工具的账号申请与入口见[服务](/services/)。
