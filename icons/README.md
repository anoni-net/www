# 圖示

頁面用到的圖示，建置時由 `build.py` 的 `icon()` 內嵌進 HTML，不透過字型或 CDN 載入，onion 版本一樣可用。只放用到的圖示，檔名照來源的圖示名稱。

| 檔案 | 來源 | 授權 |
|---|---|---|
| 本目錄所有 `.svg` | [Material Design Icons](https://pictogrammers.com/library/mdi/)，取自 mkdocs-material 9.7.7 隨附的 `templates/.icons/material/` | Pictogrammers Free License，全文在 [`LICENSE`](./LICENSE) |

跟文件站與新聞導讀用同一套圖示，文件站的 `:material-*:` 就是 Material Design Icons。

導覽列不放圖示，圖示只用在需要從幾個項目裡挑一個的地方，例如三大主題、專案與服務的卡片。
